## Run perks

A picked perk lasts for the rest of the island. The age column shows when it can appear in an offering. **I+** means Age I onward, and **I–IV** includes both endpoints. A perk prerequisite requires one rank. A Wisdom prerequisite must be active on that island.

## Ancestral Wisdom

Prestige points pay for Wisdom upgrades. Each selected upgrade applies from the start of each new island.

### Existing Ancestral Wisdom

| Upgrade | Prestige points | Effect |
|---|---:|---|
| Care Package | 1 | Start each island with 25 extra Food and 25 extra Wood. |
| Fast Forward | 1 | The first expansion of each island is free. You still choose when and where to expand. |
| Peep Magnetism | 1 | Hold the left mouse button to pick up and carry up to three Peeps at once. Makes Handful eligible to appear as a run perk. |
| Productivity Boost | 1 | All resource harvests yield 25% more. |
| Stamina Boost | 1 | Peeps start each outing with 50% more stamina. |
| Tap Radius | 1 | The radius for tapping and picking up Peeps grows by 200%, to three times its base size. |
| Homing Instinct | 2 | Peeps return home instantly when their stamina runs out. |
| Lucky Start | 2 | Choose one extra run perk at the start of each island. |
| Vagabonds | 2 | Start each island with a Tent and one extra Peep by the pier. |
